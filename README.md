* **Real-Time SVG Roller Coaster Physics:** A 9-carriage train spelling `P O R T F O L I O` smoothly banks and curves along an intricate green structural truss bridge using tangent vectors (`Math.atan2(dy, dx)`).
* **Interactive Web Audio Steam Whistle:** Synthesizes an authentic two-tone steam train whistle in pure browser Web Audio API (zero external assets/network requests).
* **Live Smoke Particle Engine:** Dynamic steam puffs emitted from the lead locomotive's smoke stack as it accelerates across the bridge.
* **Daylight & Twilight Express Toggle:** Switch seamlessly between vintage cream paper canvas (`#faf8f5`) and neon-emerald midnight mode (`#0b0f19`) with glowing rails and headlight cone beams.
* **Interactive Boost & Gear Selectors:** Click/tap & hold anywhere to accelerate up to 140 km/h, or select speed gears (`45 km/h`, `85 km/h`, `Turbo 🚀`).
