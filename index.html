PROJECT // 03 CATEGORY: PYTHON AI AGENT & TOOL USE
VERIFIED BY 114 TESTS

Taskeen — Local-First Multilingual AI Assistant

A local-first, memory-enabled personal AI assistant designed with an explicit, sandboxed tool execution architecture. Solves the safety risks of unrestrained LLM execution through a strict typed tool registry and permission boundary.

THE SAFETY PROBLEM

Giving language models direct system execution can lead to destructive file overwrites, unvetted commands, and untracked errors without recovery.

THE AGENT SOLUTION

A decoupled Execution Engine where the model only requests tool calls, which are checked against 4-tier permission levels (SAFE to DESTRUCTIVE) before execution.

VERIFIED WORKING FEATURES:
  • ✔ 114 automated unit and integration tests passing with 100% reliability
  • ✔ Typed Tool Registry with strict input/output schemas and timeouts
  • ✔ 4-Tier Permission Gate (SAFE, NORMAL, SENSITIVE, DESTRUCTIVE)
  • ✔ Persistent SQLite memory for explicit knowledge retention
  • ✔ Multilingual conversation support: English, Roman Urdu, Urdu
TECHNICAL ARCHITECTURE
Runtime: Python 3.11 (AsyncIO)
LLM Provider: Local Ollama / Swappable API
Persistence: SQLite Memory DB
Testing: Pytest (114 automated tests)
Security: Strict Permission System
TECHNOLOGIES USED
Python 3 Ollama SQLite Pytest AsyncIO

// METHODOLOGY

My Engineering Workflow

How I approach software development: from clear requirement specifications to clean relational models, defensive code, and responsible AI-assisted verification.

PHASE 01

Requirements & Scope

Clarify user workflows, determine security boundaries, and identify core data entities before writing code.

PHASE 02

Schema & Architecture

Design normalized relational schemas, define foreign keys, and establish modular directory structures.

PHASE 03

Defensive Coding

Implement clean business logic with parameter validation, session checks, and CSRF protection.

PHASE 04

AI-Assisted Verification

Use AI tools to generate edge-case test suites, audit potential vulnerabilities, and verify boundary conditions.

PHASE 05

Deployment & Docs

Write clear database setup instructions, provide environment templates (`.env.example`), and package cleanly.

How I Use AI Coding Tools Responsibly

I use modern AI coding assistants (such as Gemini, Claude, and vibe coding workflows) as an accelerator for routine boilerplate, exploratory research, and test generation. However, I maintain strict engineering oversight: every AI-generated function is audited for input validation, database query safety, and architectural cohesion. Real systems require deterministic business rules, not unverified model outputs.
